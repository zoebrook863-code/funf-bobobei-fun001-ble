适配对象为FUN-001非Pro。分析材料包括本地官方App资源、单台已授权设备的服务发现和经过脱敏的通信结构。公开测试样本使用归一化序号。

| 项目 | 值 |
| --- | --- |
| Service | 0000ee01-0000-1000-8000-00805f9b34fb |
| Write with response | 0000ee03-0000-1000-8000-00805f9b34fb |
| Notify | 0000ee02-0000-1000-8000-00805f9b34fb |
| 吸吮强度/模式记录 | 7 / 8 |
| 震动强度/模式记录 | 1 / 2 |
| 电流强度/模式记录 | 3 / 4 |

每条语义记录包含通道、操作标记和数值。封装前置一个0字节，数据按18字节分片，每片带同组标记与从1开始的片号。整18字节结尾的情况包含空数据终片。

模式1–4对应Gentle Foreplay、Flirt & Heat Up、Constant Waves、Wild Climax。名称对应关系来自App资源，实际时序尚待测量。

# 安全、失效模式与实测范围

## 断链后持续动作

单台实测 FUN-001 非 Pro 在 Windows 计划内断开 BLE 后持续动作。观察至断链后约10秒仍在运行，最后由现场人员物理关机。更长时间的固件行为尚未建立结论。

程序的命令 TTL、心跳、控制锁和 finally 清理均依赖正常运行的进程与可用 BLE 链路。进程崩溃、蓝牙断开、电脑休眠或断电时，停止写入可能无法完成。现场可立即物理关机是使用和验收条件。

## 首次验收条件

1. 使用本人拥有并明确授权控制的设备。
2. 取下设备并放在桌面，保持电源键可立即触及。
3. 按设备自身说明准备设备，结束其他 App 的占用连接。
4. 单独验证最低编码、短时动作与全停，每次改变一项参数。
5. 观察到意外动作或停止结果未知时，立即物理关机并处理软件的暂停状态。

## 已取得的观察

| 设置 | 现场反馈 |
| --- | --- |
| 震动模式1/值1，单次短测 | 观察到短暂动作并停止 |
| 吸吮模式1/值1，单次短测 | 观察到短暂动作并停止 |
| 两路各模式1/值1，电流0，约1秒目标 | 一次重测确认两种动作出现并全部停止，之前存在难以分辨的观察 |
| BLE断链 | 在约10秒观察窗口中持续动作，物理关机结束 |

范围限于一台设备和这些设置。其他个体、固件、模式、较高强度与电流非零均需要自己的现场验收。软件中的0–100为协议编码，实际输出尚未校准。

## 结果解释

- gatt_ack 表示收到 GATT/ATT 写入应答。
- 软件目标状态表示最后请求或应答中的目标。
- 物理停止依靠现场观察，接口持续将设备确认状态标为 unknown。
- 定时参数是软件目标，系统调度与 BLE 调用可能延长实际动作时间。

## 常态许可

常态许可取消授权的20分钟到期计时，按本机选择跨重启保存。重连先写归零屏障，再生成新的控制会话。它保留输出 TTL、心跳、单控制者约束与每条动作时限。

非零写入前保存待确认输出标记，确认全停后清除。未知写入、非零状态断链或带待确认输出的异常重启会暂停自动恢复。本人处理设备并在本机恢复后，重新完成归零屏障。

stop 结束当前输出会话。revoke、emergency_stop、release_control 持久撤销常态许可。操作语义见[控制指南](CONTROL_GUIDE.md)。

## 当前限制

整机重启、长时间连续使用和广泛固件兼容性仍待验收。部分 MCP SDK 测试在会话退出时打印内存流关闭警告，相关回归断言通过，长期资源行为仍需观察。历史故障实验工具保持受限入口，贡献者开展实验前需要单独审阅测试计划。
